# Wisdom Ndor — Developer Portfolio

A responsive React portfolio built with Vite.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Before publishing

- Add the live Vercel URL for the React Markdown Editor in `src/App.jsx` (`demo` field).
- Confirm that all project descriptions and links are accurate.
- Update the education details if you want to include dates.
- Deploy to Vercel with the framework preset **Vite**, build command `npm run build`, and output directory `dist`.

## Tech stack

React, JavaScript, Vite, CSS and Lucide icons.
